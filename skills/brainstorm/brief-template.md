# Template for docs/designs/YYYY-MM-DD-<slug>-brief.md

One page. Written on "lock it". The design skill starts from this, so be specific.

```markdown
# <Topic>: decision brief

Locked: <date> · Log: [brainstorm](YYYY-MM-DD-<slug>-brainstorm.md)

## The decision
<What we're going to build or do, in 2–4 sentences.>

## Why this one
- How it meets each criterion, most important first.
- Why it beat the main alternatives (one line each).

## What it is not
- Out of scope, and ideas we rejected that shouldn't come back.

## Risks and how we'll handle them
- <risk>: <mitigation, or the test that will tell us early>

## Still open
1. <question>: <recommended answer>

## For the design skill
Stages this brief already covers: <product / parts of architecture / …>
Start design at: <stage>
```
